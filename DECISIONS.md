# Architecture Decisions & Security Model (DECISIONS.md)

**Project:** Brite Spark 2026 — Agentic AI / Guardrails  
**Problem Statement:** The Caseworker's Morning  
**Policy Reference:** ACA-2026/1  

---

## 1. Why LangGraph for Workflow Orchestration
LangGraph (`app/graph.py`) provides a deterministic StateGraph for managing referral processing cycles, conditional routing, human approval gates, and error isolation.

---

## 2. Why Groq for Reasoning
Groq (`app/agent.py`) provides ultra-fast inference for structuring untrusted referral data and resident histories into clean triage notes.

---

## 3. Why Policy Engine is Separate from LLM
The policy engine (`app/policy.py`) evaluates authority rules deterministically. Instructing an LLM via prompt ("never perform protected actions") is probabilistic and insecure.

---

## 4. Hard Approval Gate & Elimination of Raw Booleans
In `app/graph.py`, `execute_action_node` checks the policy decision. If an action requires supervisor approval (`APPROVAL_REQUIRED`), execution raises a `PermissionError` unless passed a cryptographically HMAC-signed `ApprovalToken` generated by the human approval gate.

**Key Security Principle: No Raw Boolean Guardrails**
- Raw boolean variables (such as `approved=True` or `approval_granted=True`) are **NOT** used as security guardrails.
- Authorization is represented **exclusively by the presence and verification of a cryptographically signed HMAC-SHA256 `ApprovalToken`**.

The agent is structurally incapable of:
1. Executing protected actions without a supervisor's signed `ApprovalToken`.
2. Executing forbidden actions (such as `RF-2026-0415` requesting award suspension).
3. Using forged, expired, or parameter-mismatched approval tokens.

---

## 5. Handling Unknown / Ambiguous Actions
Under Policy Rule **6.1**, any action not explicitly permitted under Section 2 defaults to `APPROVAL_REQUIRED` / `ESCALATION`.

---

## 6. Failure & Error Isolation
Per-referral exception handling ensures that if history retrieval fails or an item is escalated, the workflow logs the artifact and continues processing remaining referrals.
